Connection

Connects to the KeePass desktop application over KeePassHTTP. The KeePassHTTP plugin must be installed in KeePass, and the database has to be open and unlocked for requests to work.

Connects to KeePassXC using native messaging. Enable "Browser Integration" in the KeePassXC preferences, press the "Generate Manifest" button below, and place the generated JSON file in the correct native messaging host directory for your browser.

Local File mode reads a KDBX3/KDBX4 database directly. The extension keeps an internal copy and asks for the database password when first used.

⚠ No database is created or selected yet. Create a blank database in the "Internal database" section or attach one in the "External file(s)" section below.

Internal database

The extension always uses this internal copy of a database stored in the browser. The external file provided below is only used as the source, or for the optional write-back sync.

External file(s)

Pick your existing database file and, optionally, its key file (*.key*). A copy is stored internally; changes are kept in the internal copy unless write-back sync is enabled below.

Skips all back-end databases and relies on "Secure Synced Storage" only. Credentials are stored encrypted in the browser's synced storage, so they are available on all synced devices even without a password manager installed. The synced storage is separate from the KeePass databases — it works on top of any connection type.

Password Generation

The generated password combines "Main length" random characters from pool Main characters and "Extra length" random characters from pool Extra characters, then shuffles them. Set "Extra length" to 0 for no extra characters. Used by the "Generate Password" context-menu item; the result is copied to the clipboard.
